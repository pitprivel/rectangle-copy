Rectangle Copy

Hold Alt and drag to select a rectangle – for example a single table column – and copy it to the clipboard as text.

  • In tables whole cells are copied, including merged cells (colspan/rowspan).
  • Elsewhere the text inside the rectangle is copied line by line; indentation in code is kept.
  • Works only on your computer – no data collection, no network requests.
  • English, Polski, Deutsch, Français, Italiano, Español, Українська.
